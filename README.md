# CareerTrack – Job Application Tracker 📝

### A Simple Python Mini Project

CareerTrack is a simple desktop application developed using Python to help students and job seekers manage their job applications in one place.

When applying for multiple jobs, it can sometimes become difficult to remember which companies we applied to, what positions we applied for, and whether we received any interview calls or shortlisting updates.

I developed this project to make that process easier. Instead of maintaining job details manually in different places, users can store and manage all their application information through one simple desktop application.

## 🎯 Project Objective

The main objective of this project is to create an easy-to-use application that helps users organize their job application details and track their application progress.

## ✨ Features

- **Add Applications:** Add company names, job roles, locations, application dates and other details.
- **View Applications:** View all saved job applications in one place.
- **Update Applications:** Update job details and application status whenever necessary.
- **Delete Applications:** Remove incorrect or unwanted records.
- **Search Applications:** Quickly find applications using company names or job roles.
- **Dashboard:** Get a quick overview of job application progress.
- **Status Tracking:** Track applications as Applied, Shortlisted, Interview or Rejected.
- **Database Storage:** Save application details locally using SQLite.

## 🛠️ Technologies Used

- Python 3 – Main programming language
- Tkinter – Graphical User Interface (GUI)
- SQLite – Database management
- SQLite3 – Connecting Python with SQLite
- Visual Studio Code – Development environment

## ⚙️ How It Works

1. The user enters job application details through the desktop interface.
2. Python processes the entered information.
3. SQLite stores and manages the application records.
4. The saved information is displayed in the application.
5. Users can add, view, update, search and delete their records whenever needed.

## 💡 Real-Life Use

This project is especially useful for students, fresh graduates and job seekers who apply to multiple companies during placement drives or off-campus recruitment.

It helps them maintain their application history, check their progress and avoid losing track of important job details.
